# Turnside brand kit

Open index.html for the visual brand guide. All logo and cover assets are editable SVG. tokens.json and tokens.css provide reusable color, spacing, type, and component decisions.

Primary tagline: **A good plan. A few unexpected turns.**

The application uses this identity: a white system-font interface, wayfinding blue, coral discoveries, translucent map controls, and source-backed mint-to-coral density signals. Provider marks identify sources and destinations, not sponsorship.

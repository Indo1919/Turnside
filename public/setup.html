This guide is for the person running the prototype. The sample conversation, NYC hot areas, calendar export and map work without keys.

1. Connect Gemini

Copy .env.example to .env.local in the app folder. Add your private key, then restart the app. 

GEMINI_API_KEY=your_private_key
GEMINI_MODEL=gemini-3.8-flash
GEMINI_VOICE_ENABLED=true
GEMINI_LIVE_ENABLED=true
GEMINI_TTS_VOICE=Kore

Get a key through Google AI Studio. Keep it on the server. Never paste private keys into the app or commit them.

Live voice uses gemini-3.8-live. Recorded voice input uses Gemini 3.8 Flash; Listen uses Gemini 3.8 Flash TTS. Account/model access and provider credits are required.

2. Resolve live places and routes

Enable Places API (New) and Routes API in your Google Cloud project, then configure a private server key. Separate keys can also be used; see the included integration guide. 

GOOGLE_MAPS_SERVER_KEY=your_private_server_key

This supplies real place identities and coordinates for selectable live recommendations. Without Places, grounded citations can be explored on Google Maps but cannot be added to a scheduled day.

3. Enable the full Google basemap (optional)

The free Google Maps viewer is already included. For Google Maps with custom pins and area overlays, enable Maps JavaScript API and use a separate browser key restricted to the app origin. 

GOOGLE_MAPS_BROWSER_KEY=your_restricted_browser_key
Provider configuration is not a verified connection. Test search, voice and places with your account before a live demo. No ticket purchase or reservation is made automatically.

The shared demo works in your browser: conversation, NYC hot areas, itinerary edits, calendar export and maps need no installation or API keys. This connection guide is for the app owner.

Choose where to configure it

On the hosted app, add credentials as private runtime secrets through the site's owner controls. For a local copy, use .env.local in the app folder and restart the server. Private keys never belong in frontend build variables or source control.

No Gemini or Google provider credentials are currently configured. Public NYC inventory and weather are fetched when available; fallback data is labeled. The heatmap measures mapped place density, not live crowds, TikTok popularity or Google search volume.

1. Connect Gemini

Set these runtime values on the hosted app. Locally, copy .env.example to .env.local, add your private key and restart the app. 

GEMINI_API_KEY=your_private_key
GEMINI_MODEL=gemini-3.8-flash
GEMINI_VOICE_ENABLED=true
GEMINI_LIVE_ENABLED=true
GEMINI_TTS_VOICE=Kore

Get a key through Google AI Studio. Keep it on the server. Never paste private keys into the app or commit them.

Live voice uses gemini-3.8-live. Recorded voice input uses Gemini 3.8 Flash; Listen uses Gemini 3.8 Flash TTS. Account/model access and provider credits are required.

Hosted live AI requires native ChatGPT sign-in before using provider credits. Use the app's Sign in to use Gemini link. The public demo remains available without sign-in.

2. Resolve live places and routes

Enable Places API (New) and Routes API in your Google Cloud project, then configure a private server key. Separate keys can also be used; see the included integration guide. 

GOOGLE_MAPS_SERVER_KEY=your_private_server_key

This supplies real place identities and coordinates for selectable live recommendations. Without Places, grounded citations can be explored on Google Maps but cannot be added to a scheduled day.

3. Enable the full Google basemap (optional)

The keyless Google Maps viewer is already included. For Google Maps with custom pins and area overlays, enable Maps JavaScript API and use a separate browser key restricted to the app origin. 

GOOGLE_MAPS_BROWSER_KEY=your_restricted_browser_key

4. Keep chosen places consistent

Hosted planning uses a private RECOMMENDATION_SIGNING_SECRET of at least 32 random characters. It signs short-lived selections so another server instance can build the day from the places you chose. The hosted secret is already configured; local copies can omit it.

Provider configuration is not a verified connection. Test search, voice and places with your account before a live demo. No ticket purchase or reservation is made automatically.
